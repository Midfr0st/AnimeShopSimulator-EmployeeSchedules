# Установка расписания работников

[Вернуться на главную страницу](../README.md)

## Требования

- Anime Shop Simulator для Windows;
- [MelonLoader](https://github.com/LavaGang/MelonLoader) `0.7.3`;
- [WolfCore](https://github.com/Midfr0st/AnimeShopSimulator-WolfCore) `0.2.5` или совместимая версия.

## Установка

1. Закройте игру.
2. Установите MelonLoader и один раз запустите игру.
3. Скачайте `WolfCore.dll` из [выпуска WolfCore](https://github.com/Midfr0st/AnimeShopSimulator-WolfCore/releases/latest).
4. Скачайте `WolfEmployeeSchedules.dll` из [выпуска мода](https://github.com/Midfr0st/AnimeShopSimulator-EmployeeSchedules/releases/latest).
5. Поместите обе DLL непосредственно в `Anime Shop Simulator\Mods`.

## Проверка

Откройте `Esc` → `Моды` → `Расписание работников`. Включите нужное правило для одной профессии и проверьте поведение сотрудника до открытия либо после закрытия магазина.

## Обновление и удаление

Заменяйте DLL только при закрытой игре. После удаления `Mods\WolfEmployeeSchedules.dll` сотрудники снова полностью следуют штатному расписанию игры. Файл настроек можно оставить или удалить.
